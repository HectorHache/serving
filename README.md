# Pokémon Z Research & Archive Site (SpaceBunny edition)

Static research builds and testing pages published for public inspection. This directory holds the active deployment build for Pokémon Z research, presenting the full game breakdowns, Pokédex, battle rosters, sprites, and source notes.

The site is served directly via GitHub Pages and routed to `pokemonz.agentdomains.co`.

## Local preview

Open `index.html` directly in any modern browser or run a simple local web server:

```bash
python3 -m http.server 8000
```
